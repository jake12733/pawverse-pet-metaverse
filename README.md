# 🐾 PawVerse — 반려동물 메타버스 웹사이트 프로토타입

별도 빌드나 서버 설치 없이 브라우저에서 바로 실행할 수 있는 반려동물 메타버스 플랫폼 웹 틀(프로토타입)입니다.

## 폴더 구조

```text
pet-metaverse/
├── index.html          # 메인 페이지 (네비게이션, 광장 월드, 월드 맵, 아바타 스튜디오, 샵, 커뮤니티)
├── css/
│   └── style.css       # 반응형 디자인 시스템 및 컴포넌트 스타일
├── js/
│   ├── data.js         # 월드 존, NPC, 아바타 파츠, 아이템 샵, 로컬스토리지 상태 관리
│   ├── worldCanvas.js  # HTML5 Canvas 2D 인터랙티브 광장 엔진 (이동, 점프, 말풍선, 낮/노을/밤)
│   └── app.js          # UI 컨트롤러 (채팅, 커스터마이징, 코인 결제, 게시판)
└── README.md
```

## 현재 포함된 핵심 기능

1. **실시간 인터랙티브 광장 (`#world`)**
   - 마우스 클릭 또는 키보드(`WASD` / 방향키)로 반려동물 아바타 이동
   - AI NPC 반려동물(초코, 모찌, 두부, 코코) 자동 산책 및 말풍선 대화
   - 이모트 액션(하트, 신남, 간식, 점프, 인사) 및 광장 채팅 말풍선 연동
   - 낮 / 노을 / 밤(반딧불이) 시간대 전환
2. **4개 테마 월드 존 전환 (`#zones`)**
   - 햇살 공원 광장 / 포우 카페 테라스 / 무지개 메모리얼 가든 / 어질리티 아레나
3. **아바타 스튜디오 (`#studio`)**
   - 이름, 동물 종류(강아지·고양이·토끼·햄스터), 털 색상, 액세서리, 성격 태그 실시간 미리보기 및 `localStorage` 저장
4. **포우 아이템 샵 (`#shop`)**
   - 포우코인(`P`)으로 선글라스·왕관·리본 등 액세서리 구매 시 즉시 잠금 해제 및 착용
5. **집사 광장 & 추억 방명록 (`#community`)**
   - 산책일기·모임모집·무지개 편지 작성(보너스 코인 지급) 및 좋아요

## 다음 확장 로드맵 (실서비스 전환 시)

- **3D 그래픽 업그레이드**: `worldCanvas.js`를 `Three.js` / `React Three Fiber` 씬으로 교체
- **회원·DB 연동**: `data.js`의 `localStorage` 부분을 REST API / Supabase / Firebase로 대체
